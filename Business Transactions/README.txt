BUSINESS TRANSACTIONS FLASHCARDS

Files:
- index.html — flashcard page
- style.css — design and responsive layout
- script.js — cards and interactions

Includes the transactions listed in the supplied PDF, grouped into inflows and
outflows, plus a few review cards. Search, filter, flip, shuffle, restart, and
mark cards as known.

How to use:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. No installation or server is required.

Note: The PDF supplies a list of transaction names but does not define them.
Short explanations have been added to make the list usable as flashcards.
